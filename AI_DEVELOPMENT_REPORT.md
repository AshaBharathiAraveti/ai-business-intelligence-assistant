# AI Development Report
## Mini AI Business Intelligence Assistant

### 1. Project Overview

The Mini AI Business Intelligence Assistant is a Python-based application that answers natural-language questions about sales data. It uses FastAPI, SQLite, Pandas, Streamlit, and Google Gemini API.

### 2. Tools and Technologies Used

- **Python:** Application logic and analytics.
- **Pandas:** CSV processing and data cleaning.
- **SQLite:** Storage and SQL-based analytics.
- **FastAPI:** REST API development.
- **Streamlit:** Interactive user interface.
- **Google Gemini API:** Natural-language intent classification.
- **Pytest:** Automated testing.
- **Visual Studio Code:** Development environment.

### 3. How AI Was Used

AI assistance was used for coding guidance, debugging, test development, and documentation.

Gemini is used to classify natural-language questions into predefined analytics intents. Python functions and SQLite queries perform the actual business calculations. This design helps keep numerical results deterministic and avoids executing SQL generated by the language model.

A local fallback classifier supports recognized questions when the Gemini service is unavailable.

### 4. Challenges and Debugging

During development, the following challenges were addressed:

- Cleaning and validating CSV data, including missing prices and invalid numeric values.
- Ensuring returned transactions are excluded from revenue calculations.
- Recognizing revenue-comparison questions before monthly-trend questions.
- Validating unsupported questions and invalid month inputs.
- Debugging test failures caused by a missing function import.
- Verifying API responses and analytics using automated tests.

### 5. Testing and Validation

The automated test suite contains 10 tests covering:

- Total revenue
- Highest-revenue product
- Revenue by region
- Monthly revenue
- Data quality
- API health
- Revenue comparison
- Valid API questions
- Unsupported questions
- Invalid month inputs

**Latest verified result: 10 tests passed.**
